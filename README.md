# UTAU-Romaji-to-Kana-Renamer
Batch rename your CV romaji WAV files into hiragana!

Are you lazy like me and want to make an UTAU voicebank but you don't want to go into another website and copy/paste every single kana character to each and every wav file?
Don't worry twin I got you! This is my first Python project (and also first github repository) for my Coding Practicum class so I figured I might do something useful. 

The renamer is very simple, all you need to do is upload your UTAU voicebank folder and the program automatically renames all of your romaji files to kana so oto'ing can be a breeze.
